# Contributing to ArkBar

Thank you for helping improve ArkBar.

1. Create a focused branch from `main`.
2. Keep changes small and explain the user-facing result.
3. Do not commit API keys, AK/SK values, SSO output, account identifiers, screenshots containing private data, build products, or local agent state.
4. Run `swift test` before opening a pull request.
5. Update both `README.md` and `README.en.md` when public behavior, setup, privacy, or limitations change.

For visual changes, include a redacted screenshot or a precise description of the tested macOS appearance. New providers must clearly document their authentication source, network endpoint, data scope, and privacy implications.
